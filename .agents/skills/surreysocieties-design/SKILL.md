# SurreySocieties Design

SurreySocieties has two design modes:

- Public society pages: expressive, student-friendly, clear join/event CTAs.
- Admin dashboards: plain, reliable, dense, fast.

## Workflow

1. Use ui-ux-pro-max to define the visitor or admin job, first action, required states, and risks.
2. Use reference-research only when useful:
   - Godly for public AI, Business, and Neurotech page direction.
   - Refero for event sections, committee pages, resource hubs, content layouts.
   - Mobbin for admin, invites, roles, settings, empty states.
3. Use frontend-design for page structure, responsive behavior, components, and QA.
4. Use motion-design for public-page animation plans.

## Project Rules

- AI can feel futuristic and interactive, but must still surface events and join actions early.
- Business should feel credible, sharp, and opportunity-led.
- Neurotech should feel student-friendly, scientific, and accessible.
- Admin must avoid spectacle.
- Public motion should support identity and discovery, with reduced-motion fallback.
- For the /ai robot-head hero: use Three.js for the robot and Anime.js for scroll choreography or reveals only.
